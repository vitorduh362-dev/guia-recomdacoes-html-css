 Guia de Recomendações - HTML e CSS

Mini-site estático desenvolvido como atividade prática da disciplina de Internet e Aplicações WEB do Instituto Federal do Piauí (IFPI).

Descrição
A página funciona como um guia interativo de recomendações de filmes e séries, estruturado com HTML5 semântico e estilizado com CSS moderno (incluindo gradientes, fontes externas e layout responsivo).

 Tecnologias Utilizadas
HTML5 : Estruturação semântica das páginas, tabelas, seções, listas ordenadas/não ordenadas, imagens e links internos/externos.
 CSS3 : Estilização visual, layout centralizado com max-width, fontes customizadas do Google Fonts, efeitos de hover em links e design responsivo para imagens e cards.
